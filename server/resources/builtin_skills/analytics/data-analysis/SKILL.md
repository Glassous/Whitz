# 数据分析技能

处理 CSV、Excel（XLSX）或定量数据问题时：

1. 先用 `list_workspace_files` 与 `read_workspace_file` 检查字段名、样本行与数据规模。
2. 若需精确统计计算或数据验证，使用 `execute_code`（Python）完成聚合、相关性或校验，并在执行前清晰说明代码用途等待用户审批。
3. 输出结果包含关键指标表、异常值说明与可验证结论；若生成完整报告或图表 HTML，可写入工作区文件。
